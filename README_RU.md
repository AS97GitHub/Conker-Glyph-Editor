# Conker Glyph Editor

### Визуальный редактор глифов шрифтов Conker: Live & Reloaded (формат CAFF).

</td>
</tr>
</table>

## Файлы

- `conker_glyph_format.py` — библиотека для чтения и записи формата шрифта и управления хеш-таблицей символов с открытой адресацией (обязательна для работы редактора)
- `conker_texture.py` — чтение и замена текстуры Gray8, встроенной в `.bin` (используется библиотекой и редактором)
- `conker_clipboard.py` — работа с буфером обмена для изображений (копирование / вставка текстуры)
- `conker_glyph_editor.py` — основной графический редактор (tkinter)

Все файлы должны находиться в одной папке.

## Установка (Windows)

### Вариант 1 — Скачать готовый исполняемый файл

Скачайте последнюю версию `.exe` со страницы [Releases](https://github.com/AS97GitHub/Conker-Glyph-Editor/releases).

> Устанавливать `python` и дополнительные зависимости не требуется.

### Вариант 2 — Запуск из исходников

1. Убедитесь, что установлен Python 3.8 или новее (tkinter входит в стандартную поставку Python для Windows, отдельно устанавливать его не нужно).
2. Установите Pillow:

   ```
   pip install Pillow
   ```

> В Linux для копирования / вставки текстуры через `Ctrl+C` / `Ctrl+V` дополнительно требуется установленный `xclip` (X11) или `wl-clipboard` (Wayland).

## Запуск

> ⚠️ В Windows для запуска скрипта можно использовать `python` или `py` — в зависимости от того, как установлен Python.

> ⚠️ В Linux вместо `python` может потребоваться `python3`.

```bash
python conker_glyph_editor.py
```

Или сразу передайте файл шрифта:

```bash
python conker_glyph_editor.py путь\к\default.bin
```

## Использование

1. **"Open .bin..."** — выберите файл шрифта (например, `default.bin` из `ConkerFont`). **Профиль** (`ConkerFont` / `ConkerFontJapanese` / `FrontendTitle` / `FrontendTitleJapanese`) **определяется автоматически** по байтовой сигнатуре. Текстура читается из `.bin` и сразу показывается на канвасе.
2. **Текстура:** хранится внутри `.bin` (линейный Gray8).
   - **"Export texture..."** — сохранить в PNG (Gray8).
   - **"Import texture..."** — заменить на PNG/BMP. Ширина — кратна 64 (до 4096). При смене размера спрашивается: **оставить** прямоугольники глифов на тех же пикселях или **масштабировать** вместе с текстурой. Запись в файл — при сохранении `.bin`.
   - **Ctrl+C** копирует текстуру в буфер обмена, **Ctrl+V** вставляет изображение из буфера как новую текстуру (горячие клавиши не срабатывают, пока фокус в текстовом поле).
3. **Вкладки слева — Glyphs / Charmap / Help:**
   - **Glyphs** — список в виде `index  char=… (U+XXXX)`. Выбранный глиф подсвечивается голубым прямоугольником с маркерами.
   - **Charmap** — назначенные символы и пустые слоты хеш-таблицы на 2048 записей.
   - **Help** — краткая справка по управлению.
4. **Визуальное редактирование и свойства:**
   - Угловой маркер — изменить размер прямоугольника (`Start X/Y`, `End X/Y`). **Glyph Width / Height** пересчитываются по новому размеру.
   - Центр прямоугольника — перемещение.
   - Вручную редактируйте метрики на правой панели и нажимайте **"Apply Changes"**:
     - **X Offset / Y Offset** — задаёт смещение символа (знаковое, -128…127).
     - **Glyph Width / Glyph Height** — физический размер глифа на экране (растягивает/сжимает глиф по осям X/Y). В UI отображается stored -1.
     - **Advance** — шаг до следующего символа (младший байт advance (int16)). Для U+0020 игра берёт **Space Width** из Font Metrics.
     - **Kerning** — в оригинальных шрифтах всегда -1.
     - **Ascent** — в конце записи глифа (часто совпадает с высотой; отдельного эффекта на экране не подтверждено).
5. **Font Metrics** (справа, на весь шрифт):
   - **Line Height**, **Space Width**, **Fallback** (например `U+25A1`).
   - Размер атласа и max probes — только для просмотра.
6. **Character Management:** действие → поля → **"Apply"**:
   - **add** — доп. символ / `U+XXXX` к глифу.
   - **remove** — снять символ из **Old Char** (хотя бы один должен остаться).
   - **replace** — заменить **Old Char** на **New Char**.
   - **new_glyph** — добавить новый глиф в конец таблицы глифов как копию выбранного, чтобы его сразу было видно и можно было редактировать. Поле **New Char** необязательно и привязывает символ к новому глифу. Файл увеличивается: все размеры, смещения и контрольная сумма заголовка обновляются автоматически.
   - **delete_glyph** — удалить выбранный глиф: его символы отвязываются, все последующие глифы смещаются на один индекс вниз. Файл уменьшается. Перед удалением запрашивается подтверждение; после сохранения действие необратимо.
7. **Сохранение:**
   - **"Save As..."** — сохранить в новый файл.
   - **"Save (overwrite)"** — перезаписать открытый файл.

Редактор аккуратно изменяет записи глифов и перестраивает фиксированную хеш-таблицу из 2048 слотов, не разрывая цепочки пробирования и не повреждая прочие области файла. При добавлении или удалении глифов контейнер полностью перекладывается (таблица символов, выравнивающий отступ, ресурс текстуры, метаданные, размеры секций), а при сохранении обновляются контрольная сумма заголовка и лимит пробирования таблицы символов — поэтому сохранённый файл всегда принимается игрой.

## Важное примечание

Координаты атласа — в фиксированной 14-битной сетке (`UV_RANGE = 16384`):

```
pixel = raw / DIV + OFFSET
DIV   = 16384 / actual_texture_size_in_pixels
OFFSET = -0.5   (все поставляемые профили)
```

Запись глифа (18 байт, little-endian): `x_offset (int8)`, `y_offset (int8)`, `width (uint8)`, `height (uint8)`, `u0,u1,v0,v1 (uint16)`, `advance (int16)`, `kerning (int16)`, `ascent (int16)`.

**X/Y Offset**, **Glyph Width/Height** и **Advance** **подтверждены в игре через XEMU**. **Kerning** в оригинале всегда -1; у **Ascent** отдельного эффекта на экране не подтверждено. Крупные правки проверяйте в игре.
